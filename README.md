# Coding Journey

This repository documents my progress learning Python and software development through practical projects.

## Projects

### Tip Calculator

A command-line calculator that:

- Calculates a tip percentage
- Calculates sales tax
- Splits the total between multiple people
- Handles invalid input

Run it with:

```bash
python3 tip_calculator.py
```

### Personal Expense Tracker

A command-line expense tracker that:

- Adds and saves expenses
- Displays all expenses
- Calculates total spending
- Calculates totals by category
- Deletes expenses
- Saves data in a JSON file

Run it with:

```bash
python3 expense_tracker.py
```
### Inventory Management System

- Adds and removes products

- Prevents duplicate product IDs
